# Rock Paper Scissors

A console-based implementation of the classic Rock Paper Scissors game, built as part of The Odin Project's Foundations curriculum.

## Description

This project is a beginner-friendly JavaScript exercise. The entire game is played directly in the browser's developer console using standard dialog boxes (`prompt`) for user input and console outputs (`console.log`) for game progress, scores, and round results. There is intentionally no graphical user interface (GUI) or web page styling.

## Technologies Used

- HTML5 (minimal markup to link the script)
- Vanilla JavaScript

## Rules of the Game

- **Rock** beats **Scissors**
- **Scissors** beats **Paper**
- **Paper** beats **Rock**
- Matching choices result in a tie (no points awarded)

The game consists of 5 rounds. After 5 rounds, the final scores are tallied and the overall winner is announced.

## How to Run the Game

1. Clone or download this repository to your local machine.
2. Open `index.html` in any modern web browser (Google Chrome, Firefox, Microsoft Edge, Safari).
3. Open the browser's developer console before or when loading the page (see instructions below).
4. When prompted, type `rock`, `paper`, or `scissors` (input is case-insensitive, e.g., `ROCK`, `Paper`, or `scissors`).
5. After 5 rounds, review the round-by-round results and final score in the developer console.
6. To play again, simply refresh the browser tab.

## How to Open the Browser Console

- **Google Chrome / Microsoft Edge / Brave:**
  - Press `F12` or `Ctrl + Shift + J` (Windows / Linux) or `Cmd + Option + J` (macOS).
  - Alternatively, right-click anywhere on the blank page, select **Inspect**, and click on the **Console** tab.
- **Mozilla Firefox:**
  - Press `Ctrl + Shift + K` (Windows / Linux) or `Cmd + Option + K` (macOS).
  - Or right-click, select **Inspect**, and switch to the **Console** tab.
- **Apple Safari:**
  - Enable Developer Menu in Safari Preferences (`Settings > Advanced > Show features for web developers`).
  - Press `Cmd + Option + C` to open the console.
